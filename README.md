A tiny Node 22 program that writes one short, slow text to `/output/entry.txt` — a tide, some gulls, and a stone still turning smoother under the surface — written to relax the AI judge reading it.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network access, no dependencies. The output is a single UTF-8 text of 1 to 280 characters.
